# نظام النسيم V60.2 — إصلاح تصدير تقرير أداء مبيعات الموظفين

- إصلاح زر «تصدير إلى ملف جدول بيانات» في صفحة أداء مبيعات الموظفين.
- أصبح التصدير يستخدم ملف Excel بصيغة XLS متوافق مع Excel بدل مسار CSV السابق.
- يتضمن الملف الأقسام الثلاثة الظاهرة في التقرير: ملخص أداء الموظفين، تفاصيل مبيعات إضافات التشغيل، وسجل التعديلات والإجراءات على الحجوزات.
- يلتزم التصدير بالفلاتر الحالية لأن البيانات المصدرة هي نفس نتيجة التقرير المعروضة.
- في حالة عدم وجود بيانات، تظهر رسالة واضحة بدل إنشاء ملف فارغ.
