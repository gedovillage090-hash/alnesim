تحديث V57.4 — ملاحظات أوامر التشغيل وإدارة العروض

1) أضيف حقل «ملاحظات أمر التشغيل» قابل للكتابة لكل أمر، مع زر حفظ مستقل. تُحفظ الملاحظات في قاعدة البيانات وتظهر عند طباعة أمر التشغيل.
2) أضيف زر «تعديل» للعرض لتعديل الاسم ونوع/قيمة الخصم وتاريخ البداية والنهاية.
3) أضيف زر «مسح» للعروض. يمنع النظام حذف أي عرض مرتبط بحجز، لتجنب التأثير على سجلات الحجوزات؛ يمكن إيقاف العرض بدلًا من ذلك.
4) تم الإبقاء على آلية تفعيل/إيقاف العرض الموجودة.

التحقق: node --check server.js و node --check public/app.js.
لم يتم اختبار واجهة الطباعة أو عمليات الحفظ على قاعدة بيانات تشغيل حية.
