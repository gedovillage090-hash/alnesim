# تحديث V56.5 — احتساب الوجبات الهدية ضمن مشروبات المخزن

## القواعد المعتمدة
- عدد الأفراد المستخدم للمشروبات = عدد الوجبات الفعلية المرتبطة بصنف المشروب + عدد الوجبات الهدية في الحجز.
- المياه: زجاجة واحدة لكل 5 أفراد، مع التقريب لأعلى.
- السوفت درينك: علبة واحدة لكل 12 فردًا، مع التقريب لأعلى.
- الوجبات الهدية المسجلة في `bookings.free_meals` تُضاف مرة واحدة لكل صنف مشروب مجمّع، ولا تُكرر لكل سطر داخل البوفيه.
- أصناف المشروبات الأخرى تحتفظ بطريقة حسابها الحالية.
