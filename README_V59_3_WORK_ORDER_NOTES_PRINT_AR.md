# نظام النسيم V59.3 — إظهار ملاحظات أوامر الشغل في الطباعة

- زر الطباعة يقرأ أحدث نص موجود في مربع ملاحظات أمر التشغيل.
- إذا كانت الملاحظات قد تغيرت ولم يتم الضغط على حفظ، يحفظها النظام أولًا ثم يطبعها.
- بعد حفظ الملاحظات يتم تحديث نسخة أمر الشغل الموجودة في الواجهة حتى لا تطبع بيانات قديمة.
- تنسيق الطباعة يحافظ على الأسطر الجديدة ويمنع قص صندوق الملاحظات بين الصفحات.
- الخادم كان يعيد notes ضمن work_orders عبر wo.*؛ لم تتغير قاعدة البيانات أو API.
