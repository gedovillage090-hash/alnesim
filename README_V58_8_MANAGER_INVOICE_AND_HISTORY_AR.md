# نظام النسيم V58.8 — تصحيح الفاتورة التقديرية وسجل قرارات المدير

## أولًا: الفاتورة التقديرية عند تعديل الحجز
- سبب استمرار المشكلة أن شاشة تعديل الحجز تستخدم الفاتورة الحية `#liveTotal`، بينما تعديل V58.7 كان قد عدّل معاينة أخرى داخل نموذج تعديل منفصل.
- الآن عند فتح الحجز يتم تحميل `special_discount` المعتمد من المدير إلى نموذج التعديل.
- الفاتورة الحية تعرض بند الخصم الإضافي المعتمد من المدير وتطرحه من المطلوب شامل التأمين.
- تمت إضافة تنظيف قيمة الخصم عند الخروج من وضع التعديل حتى لا تنتقل لحجز آخر.
- لا يتم تعديل قيمة الخصم في قاعدة البيانات ولا إعادة تطبيقه؛ الحساب للعرض فقط.

## ثانيًا: سجل قرارات المدير التفصيلي
- إضافة سجل في صفحات طلبات الموافقات يعرض آخر 500 عملية.
- يشمل اعتماد/رفض الخصم الإضافي، اعتماد/رفض خصم الموظف، اعتماد/رفض تعديل أو إلغاء، تعديل بيانات الحجز من المدير، التأجيل، والإلغاء.
- يعرض وقت العملية، الإجراء، رقم الحجز والعميل، القاعة والموعد، اسم المدير، والمبلغ/النسبة/سبب الطلب/ملاحظة القرار أو فروق التعديل حسب نوع العملية.
- السجل للمدير فقط.
- السجلات القديمة التي لم تكن تحفظ تفاصيل الفروق لا يمكن استرجاع معلومات لم تكن محفوظة؛ سيعرض السجل تنبيهًا بأن التفاصيل غير متاحة عند الحاجة. العمليات الجديدة تسجل بيانات الطلب والموافقة في جداول الطلبات وسجل نشاط الحجز.
