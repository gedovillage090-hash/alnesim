# نظام النسيم V59.4 — ترك عمود ملاحظات البنود فارغًا في الطباعة

- إزالة أي نص تلقائي أو تفاصيل بند من عمود «ملاحظات» في جدول أمر الشغل المطبوع.
- يظل عمود الملاحظات موجودًا وفارغًا بالكامل ليتم تدوين الملاحظات يدويًا.
- لا تغيير على بيانات البنود أو ملاحظات أمر التشغيل العامة في القسم المنفصل.
- لا تغيير على قاعدة البيانات أو آلية حفظ الملاحظات.
