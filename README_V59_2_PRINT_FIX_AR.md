# نظام النسيم V59.2 — إصلاح طباعة العقد الابتدائي وإقرار الغرفة

## سبب المشكلة والإصلاح
1. العقد الابتدائي: كان CSS يطبق `break-inside: avoid` على كل `section`، بينما بيانات العقد الابتدائي مجمعة داخل section طويلة. المتصفح كان ينقل القسم كاملًا للصفحة التالية ويترك الصفحة الأولى بعنوان العقد فقط. تم السماح للقسم الرئيسي بالانقسام الطبيعي بين الصفحات مع الحفاظ على صفوف الجداول قدر الإمكان.
2. إقرار تعليمات الغرفة: كان مسار الطباعة يحتوي شرطًا منسوخًا من العقد النهائي يستخدم المتغير `kind` غير الموجود في دالة الإقرار، ما يسبب ReferenceError ويوقف الطباعة. تم حذف الشرط الخاطئ؛ الإقرار يطبع مباشرة بعد تحميل بيانات الحجز.
