# نظام النسيم V58.7 — إظهار الخصم الإضافي المعتمد في الفاتورة التقديرية

- تمت مراجعة شاشة تعديل الحجز والفاتورة التفصيلية الحية.
- كانت المعاينة تحسب الإجمالي من الأصناف والتأمين والمدفوعات، لكنها لا تطرح `special_discount` المعتمد من المدير.
- أضيف سطر مستقل باسم «الخصم الإضافي المعتمد من المدير» ويظهر عند وجود خصم معتمد.
- أصبح الإجمالي التقديري شامل التأمين بعد الخصم المعتمد.
- أصبح الرصيد التقريبي = الإجمالي بعد الخصم - الدفعات السابقة (مع استبعاد رد التأمين).
- لم يتم تعديل قيمة الخصم في قاعدة البيانات أو مسار الموافقات، ولم يتم تطبيق خصم مرتين على الحجز.

## الاختبارات
- node --check public/app.js
- node --check server.js
- npm run check
