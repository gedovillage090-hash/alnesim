# نظام النسيم V59.7 — مميزات مستقلة لكل باكدج قاعة

## إدارة الباكدجات
- كل باكدج مرتبط بالفعل بقاعة محددة؛ تم توسيع شاشة إضافة/تعديل الباكدج لتسجيل «مميزات الباكدج الخاصة بالقاعة» وكل ميزة في سطر مستقل.
- يمكن تسجيل ميزات مثل DJ، تصوير، كوشة، ديكور، دانس فلور وغيرها لكل باكدج على حدة.
- تظهر المميزات في جدول الباكدجات، ويمكن تعديلها دون تغيير سعر أو بيانات الباكدج.
- حقل المميزات اختياري، ويمكن تركه فارغًا.

## الحجز
- عند اختيار القاعة والفترة، تظهر الباكدجات المرتبطة بهذه القاعة فقط (السلوك الموجود سابقًا).
- عند اختيار الباكدج، تظهر مميزاته الخاصة في معاينة الحجز.
- الباكدج الذي ليس له مميزات خاصة يستخدم المميزات العامة القديمة كخيار احتياطي للمحافظة على البيانات الحالية.

## أوامر التشغيل والعقود
- أمر تشغيل القاعة يعرض مميزات الباكدج المحدد أسفل بيانات الحجز.
- العقد الابتدائي والنهائي يعرضان المميزات الخاصة بالباكدج المحجوز.
- بيانات المميزات تأتي من سجل الباكدج المرتبط بالحجز، ولا تعتمد على اختيار حالي مختلف أو باكدج قاعة أخرى.
- أوامر المطبخ والمخزن لا تعرض هذا القسم.
