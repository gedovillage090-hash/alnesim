# نظام النسيم V59.1 — إظهار بيانات الحجز وإجراءاته في نتائج بحث الموبايل

- نتائج البحث برقم الموبايل أصبحت تعرض بيانات الحجز التفصيلية: رقم الحجز، الحالة، العميل، الهاتف، القاعة، الباكدج، الموعد، عدد الأفراد، إجمالي المناسبة، التأمين، الخصم الإضافي المعتمد، الإجمالي النهائي، المدفوع، المتبقي، والتعديلات المالية وملاحظات قرارات المدير.
- إضافة أزرار تفاصيل الحجز، طباعة العقد الابتدائي، طباعة العقد النهائي، طباعة إقرار تعليمات الغرفة، والتحصيل/سجل الدفعات.
- أزرار الطباعة تحترم صلاحيات المستخدم، والمدير لديه صلاحية الطباعة.
- تم توسيع استجابة استعلام الهاتف لتشمل booking id والخصم المعتمد والإجمالي النهائي.
- زر عرض كل الحجوزات ما زال يعيد الجدول والملخصات العامة.
