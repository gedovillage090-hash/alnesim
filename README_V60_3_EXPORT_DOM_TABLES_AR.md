# نظام النسيم V60.3 — إصلاح جذري لتصدير أداء مبيعات الموظفين

- تم تغيير آلية التصدير لتقرأ الجداول المعروضة فعليًا في الصفحة بدل الاعتماد على كائن البيانات الداخلي أو دالة تصدير Excel السابقة.
- يصدر التقرير ثلاثة أقسام: ملخص أداء كل موظف، تفاصيل مبيعات إضافات التشغيل، وسجل التعديلات والإجراءات.
- يصدر CSV بترميز UTF-8 مع BOM ودعم علامات الاقتباس وفواصل الأسطر، ليفتح مباشرة في Excel وبرامج الجداول.
- التصدير يستخدم نفس النتائج المعروضة بعد تطبيق الفلاتر.
- تم ربط الزر بمستمع click مباشر بعد بناء صفحة التقرير، مع معالجة أخطاء التصدير برسالة واضحة.
- لا توجد تغييرات على قاعدة البيانات أو بيانات الحجوزات.
