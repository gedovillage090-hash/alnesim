# نظام النسيم V59.9 — إظهار تفاصيل الباكدج كاملة في أمر تشغيل القاعة

- إصلاح مصدر البيانات: استعلام أوامر التشغيل كان يقرأ مميزات الباكدج الخاصة فقط؛ أصبح يستخدم مميزات الباكدج، وإذا كانت فارغة يستخدم المميزات العامة الاحتياطية التي كانت تظهر في شاشة الحجز.
- عرض كل ميزة كسطر مستقل داخل قسم واضح بعنوان «مميزات وتفاصيل باكدج القاعة» مع اسم الباكدج.
- يقتصر العرض على أمر تشغيل القاعة فقط. لا يظهر في أمر تشغيل المطبخ أو المخزن، ولا في شاشة الحجز أو العقود.
- لا تغيير في قيم الباكدج أو الفواتير أو بيانات الحجوزات.
