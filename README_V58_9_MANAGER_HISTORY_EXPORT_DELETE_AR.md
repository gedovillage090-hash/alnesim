# نظام النسيم V58.9 — تصدير سجل قرارات المدير وصلاحية المسح

## التصدير
- زر «تصدير Excel» في سجل قرارات المدير.
- ينشئ ملف CSV بترميز UTF-8 مع BOM ومتوافق مع Microsoft Excel، ويحتوي على التاريخ والوقت، الإجراء، رقم الحجز، العميل، القاعة، الباكدج، الموعد، عدد الأفراد، المدير، الحالة، والتفاصيل.
- التصدير يشمل حتى 5000 سجل متاح من سجل قرارات المدير.

## الصلاحيات
- إضافة صلاحية قسم «سجل قرارات المدير» لتحديد من يستطيع فتح السجل.
- إضافة صلاحية خاصة مستقلة «مسح سجل قرارات المدير فقط» تظهر ضمن الصلاحيات الخاصة والحساسة في شاشة المستخدمين.
- يمكن تفعيلها أو إلغاؤها لكل مستخدم.
- زر المسح لا يظهر إلا للمدير أو المستخدم الذي يحمل الصلاحية.
- الخادم يتحقق من الصلاحية ومن نوع السجل قبل المسح.
- المسح يحذف سجل المتابعة فقط ولا يلغي القرار الأصلي ولا يغير الحجز أو الخصم المعتمد. ويسجل النظام عملية المسح في سجل التدقيق العام.
