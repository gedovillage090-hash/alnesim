# نظام النسيم V60.0 — باكدج القاعة من شاشة القاعات إلى الحجز وأمر التشغيل

## ما تم
- إضافة حقل «تفاصيل باكدج القاعة» إلى شاشة إضافة وتعديل القاعات، وكل ميزة/خدمة في سطر مستقل.
- إظهار تفاصيل باكدج القاعة للموظف داخل شاشة إنشاء/تعديل الحجز بمجرد اختيار القاعة، ليستخدمها في شرح ما تقدمه القاعة للعميل.
- عرض نفس التفاصيل كاملة في أمر تشغيل القاعة المطبوع، بعنوان واضح وبنقاط مستقلة.
- إزالة البنود التلقائية الكوشة وDJ والليزر وتصوير الفيديو مونو من إنشاء أمر تشغيل القاعة.
- إخفاء البنود القديمة بهذه الأسماء من عرض أوامر التشغيل الحالية أيضًا، دون حذفها من قاعدة البيانات.
- لا تظهر تفاصيل الباكدج في أوامر المطبخ أو المخزن.

## قاعدة البيانات
- إضافة ترحيل آمن تلقائي لعمود halls.package_details مع قيمة افتراضية فارغة، دون حذف أو تعديل بيانات القاعات الحالية.
- الإبقاء على hall_packages.terms كخيار توافق قديم، لكن المصدر الأساسي للتفاصيل أصبح halls.package_details.
