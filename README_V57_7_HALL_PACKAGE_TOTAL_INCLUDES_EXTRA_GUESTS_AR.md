# V57.7 — إجمالي باكدج القاعة شامل الأفراد الإضافيين

- في العقد الابتدائي والنهائي، أصبح بند «باكدج القاعة» يعرض سعر الباكدج الأساسي + إجمالي الأفراد الإضافيين في قيمة واحدة.
- لا يظهر بند منفصل للأفراد الإضافيين في تفاصيل العقد.
- في إيصالات استلام المبالغ، أضيف ملخص «باكدج القاعة شامل الأفراد الزيادة» بنفس الإجمالي، دون عرض الأفراد الإضافيين كبند مستقل.
- التعديل للعرض والطباعة فقط؛ لم يغير قيم الحجز المحفوظة أو طريقة احتساب المبلغ المستحق.
