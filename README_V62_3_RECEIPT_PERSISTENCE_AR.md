V62.3 — حماية سجل التحويل والاستلام من إعادة الإصدار غير الضرورية

- إعادة إصدار/تحديث أوامر التشغيل لا تنشئ إصدارًا جديدًا عند إعادة المراجعة دون أي تعديل في بيانات الحجز.
- تتم مقارنة نسخة محفوظة من بيانات الحجز الأساسية والتفاصيل المرتبطة به (البوفيهات، الإضافات، الخدمات، غرف العروسة).
- إذا لم يتغير الحجز: يبقى نفس رقم الإصدار، وتظل حالة تم الاستلام واسم المستلم والتاريخ والوقت محفوظة بعد التحديث.
- إذا تغيرت بيانات الحجز: ينشأ إصدار جديد، وتظل سجلات التحويل والاستلام للإصدار القديم محفوظة، ويحتاج الإصدار الجديد إلى تحويل واستلام جديدين.
- الأوامر القديمة التي ليس لها لقطة بيانات سابقة تحصل على لقطة أساس عند أول مراجعة دون إبطال سجل استلامها الحالي.
- تحديث كاش الواجهة.

التثبيت: أوقف السيرفر، استبدل ملفات المشروع، احتفظ بقاعدة البيانات ومجلد data كما هما، ثم أعد تشغيل السيرفر.
