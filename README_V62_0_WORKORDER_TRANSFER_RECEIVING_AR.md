# V62.0 — ربط تحويل أوامر التشغيل بالاستلام

## ما الجديد
- أمر المطبخ والمخزن لا يظهر في قائمة القسم إلا بعد أن يحوله موظف مخول من شاشة أوامر الشغل.
- التحويل يسجل اسم الموظف والتاريخ والوقت والإصدار في جدول مستقل `work_order_transfers`.
- الاستلام مرفوض من الخادم إذا لم يكن الإصدار محولًا للقسم.
- عند الاستلام يسجل اسم المستلم ووقت الاستلام في `work_order_receipts` كما كان سابقًا.
- شاشة أوامر الشغل تعرض حالة التحويل والاستلام واسم المحوّل والمستلم.
- شاشة سجل الاستلامات تعرض كذلك المحوّل ووقت التحويل.
- عند تحديث الحجز وإصدار نسخة جديدة، يظل سجل التحويل والاستلام للإصدار القديم محفوظًا. النسخة الجديدة لا تظهر للمطبخ/المخزن حتى يحولها موظف الريسبشن مرة أخرى.

## التثبيت
1. خذ نسخة احتياطية من المشروع وقاعدة البيانات.
2. استبدل ملفات المشروع بملفات هذه الحزمة.
3. لا تحذف أو تستبدل مجلد `data` أو ملف قاعدة البيانات الحالي.
4. أعد تشغيل السيرفر.
5. حدّث المتصفح تحديثًا قويًا.

## ملاحظة
يتم إنشاء جدول التحويلات تلقائيًا عند تشغيل السيرفر، ولا يلزم تعديل يدوي لقاعدة البيانات.
