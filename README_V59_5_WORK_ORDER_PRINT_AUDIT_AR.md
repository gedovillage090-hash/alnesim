# نظام النسيم V59.5 — تسجيل طباعة أوامر التشغيل

- عند الضغط على «طباعة أمر الشغل»، يحفظ النظام الملاحظات غير المحفوظة أولًا، ثم يسجل عملية الطباعة على الخادم قبل فتح نافذة الطباعة.
- تتحول حالة أمر التشغيل تلقائيًا إلى «تمت الطباعة».
- يسجل كل حدث طباعة في سجل تاريخ أمر التشغيل، مع المستخدم وتاريخ/وقت الخادم.
- تظهر بيانات آخر طباعة بجوار الحالة في بطاقة أمر التشغيل: التاريخ والوقت واسم المستخدم.
- عند إعادة الطباعة يسجل حدثًا جديدًا ويعرض أحدث طباعة.
- إذا تغيرت الحالة لاحقًا إلى تم التسليم/جاري التنفيذ/تم التنفيذ، تظل بيانات آخر طباعة ظاهرة.
- لا تتطلب الإضافة تعديلًا يدويًا لقاعدة البيانات؛ تستخدم جدول work_order_history الحالي.
