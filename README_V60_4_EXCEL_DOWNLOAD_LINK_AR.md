# نظام النسيم V60.4 — تصدير أداء الموظفين برابط تنزيل مباشر

- إعادة بناء تصدير صفحة أداء مبيعات الموظفين.
- زر التصدير الآن ينشئ ملف Excel-compatible بصيغة XLS (HTML workbook) من الجداول المعروضة.
- بدل الاعتماد على تنزيل تلقائي قد يمنعه المتصفح، يظهر رابط تنزيل مباشر بجوار الزر بعد تجهيز الملف؛ ينفذ المستخدم نقرة مباشرة على الرابط لتنزيل الملف.
- يضم ملخص الموظفين، تفاصيل مبيعات إضافات التشغيل، وسجل إجراءات الحجوزات.
- يقرأ نفس الجداول الظاهرة بعد الفلاتر.
- يتم إظهار رسالة واضحة إذا لم توجد بيانات أو حدث خطأ.
- لا تغييرات على قاعدة البيانات.

## خطوات الاستخدام
1. اضغط «عرض التقرير».
2. اضغط «تصدير إلى ملف جدول بيانات».
3. اضغط الرابط الجديد «تنزيل ملف Excel الجاهز» الذي يظهر بجوار الزر.
