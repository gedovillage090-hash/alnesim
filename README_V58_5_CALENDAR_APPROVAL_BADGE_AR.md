# نظام النسيم V58.5 — استعادة التقويم وتنبيهات الموافقات

## 1) التقويم
- إزالة قواعد CSS الإضافية التي كانت تغيّر أبعاد وألوان عناصر التقويم.
- الإبقاء على قواعد التقويم الأصلية الموجودة في ملف التصميم الأساسي.
- استثناء عناصر التقويم من قواعد التصميم العامة الجديدة.
- تحديث رقم إصدار ملف CSS إلى 58.5 لمنع المتصفح من استخدام نسخة قديمة من الكاش.

## 2) تنبيه طلبات الموافقات
- إضافة عداد بجوار عنوان «طلبات موافقات» في القائمة الجانبية.
- العداد يظهر لحساب المدير فقط، ويجمع الطلبات المعلقة من:
  - طلبات الخصومات.
  - طلبات الخصم الإضافي.
  - طلبات تغيير موعد الحجز أو إلغاء الحجز.
- تحديث العداد عند فتح النظام، وبعد إرسال الطلب أو اتخاذ القرار، ثم كل 60 ثانية أثناء استخدام النظام.
- الطلبات تظل في صفحات الموافقات الحالية؛ لم يتم تغيير منطق الموافقة أو قاعدة البيانات.

## الاختبارات
- node --check public/app.js
- node --check server.js
- npm run check
- فحص سلامة ملف ZIP
