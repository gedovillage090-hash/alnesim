# نظام النسيم V58.1 — شروط العقود والمنيو ورسوم ما بعد الفرح

## التعديلات
- منع طباعة العقد الابتدائي قبل تسجيل مقدم الحجز (10,000 جنيه) والتأمين كاملًا.
- منع طباعة العقد النهائي قبل سداد كامل إجمالي الحجز شامل التأمين وبعد الخصومات المعتمدة. يتم حساب المدفوعات مع استبعاد عمليات رد التأمين.
- إظهار أصناف باكدج المنيو وكمياتها وطريقة احتسابها داخل العقد الابتدائي والنهائي.
- استمرار قفل تعديل بيانات الحجز بعد تاريخ المناسبة، مع إتاحة تسجيل رسوم إضافية بعد الفرح من نافذة التحصيل، مثل فلاشة إضافية أو خدمة فيديو. يتطلب التسجيل مبلغًا وبيانًا واضحًا، ويصدر إيصال ويُسجل في حركة الخزنة. هذه الرسوم لا تغيّر تفاصيل الحجز الأصلية.
- تحديث ألوان الواجهة وإضافة انتقالات وحركات خفيفة مع احترام إعداد تقليل الحركة في الجهاز.

## الفحوصات
- `npm run check` — ناجح.
- `node --test tests/drink-quantity-rules.test.js` — ناجح، 28 تأكيدًا.
- فحص الأرشيف المضغوط — ناجح.

لم يتم إجراء اختبار شامل على قاعدة بيانات تشغيل حقيقية أو تجربة طباعة فعلية من المتصفح؛ يُنصح بتجربة الشروط على حجز تجريبي قبل الاستخدام الفعلي.
