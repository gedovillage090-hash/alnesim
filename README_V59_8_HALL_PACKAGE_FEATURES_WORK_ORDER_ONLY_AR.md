# نظام النسيم V59.8 — مميزات الباكدج في أمر تشغيل القاعة فقط

- تظل إدارة مميزات كل باكدج من شاشة باكدجات القاعات كما هي.
- تم إخفاء مميزات الباكدج من شاشة إنشاء الحجز؛ لن تظهر عند اختيار القاعة أو الباكدج.
- تم إزالة مميزات الباكدج من العقد الابتدائي والنهائي.
- تظهر مميزات الباكدج في أمر تشغيل القاعة فقط، ولا تظهر في أوامر تشغيل المطبخ/المخزن.
- يظل أمر التشغيل يأخذ المميزات من الباكدج المرتبط بالحجز نفسه.
- فحوصات الكود والاختبارات الآلية مذكورة أدناه.
