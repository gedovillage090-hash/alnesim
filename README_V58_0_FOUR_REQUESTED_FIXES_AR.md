# الإصدار V58.0 — أربعة تعديلات

1. توضيح خانة نسبة خصم الموظف في نموذج الحجز الجديد باسم صريح، مع بقاء القيمة الافتراضية 0%.
2. إضافة إجمالي عدد الأفراد في بيانات الطباعة لجميع أوامر التشغيل. يعتمد العرض على عدد الأفراد المحفوظ في الحجز.
3. إضافة قسم مستقل «خصم إضافي» في نموذج الحجز المستخدم للإنشاء والتعديل. يمكن اختيار مبلغ ثابت أو نسبة، ويجب إدخال قيمة وسبب. بعد حفظ الحجز/التعديل يرسل النظام طلبًا إلى مسار موافقات الخصم الإضافي الحالي، ويظل الخصم غير مطبق حتى موافقة المدير. قرار المدير وسبب القرار مدعومان في مسار الموافقات الحالي.
4. إضافة تفاصيل الدفعات المسجلة إلى العقد الابتدائي، مع إجمالي المدفوع والمتبقي شامل التأمين، على غرار جدول الدفعات في العقد النهائي.

## التحقق
- `npm run check` نجح.
- `node --test tests/drink-quantity-rules.test.js` نجح (28 assertion).
- لم يتم إجراء اختبار واجهة كامل على قاعدة بيانات التشغيل الحية. يوصى بتجربة حجز جديد وتعديل حجز، وطلب خصم إضافي بالمبلغ والنسبة، ثم اختبار موافقة المدير ورفضه، وطباعة أوامر التشغيل والعقد الابتدائي.
